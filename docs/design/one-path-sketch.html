47% 是怎么算出来的？

看完整依据 →
期权市场· 中性32%交易者用真金白银押出来的看法占 37%ⓘ 细节

按期权市场（交易者用真金白银押未来价格的地方）的价格推算，这件事约有 32% 的可能。这个数含有交易者对风险的要价，不等于真实的可能性；期限或目标价超出现有期权时，是从最接近的期权推算的。

平时的波动· 中性35%只看它平时涨跌有多大占 32%ⓘ 细节

按这只股票平时的波动幅度推算（不看任何消息），这件事约有 35% 的可能。它不含股票长期上涨的倾向。回测里它偏低：平均低约 8 个百分点，三年期更多。

它自己的过去＋ 支持75%过去 299 个 3 年里有 224 个做到占 32%ⓘ 细节

股价需要上涨 99%。从 1999 年起这只股票的 299 个 3 年时间段里，有 224 个在某个月末达到过这个涨幅（75%）。这是“如果它重复自己过去的表现”的结果，所以占比不到三分之一。回测里它略偏高（3 到 5 个百分点），但回测里没有涨幅特别极端的股票。这些时间段互相重叠，相当于约 9 段独立的 3 年。
